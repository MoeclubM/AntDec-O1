# AntDec 控制台

AntDec 系列的本地 USB 管理页面，使用 Vue 3、Element Plus、TypeScript 和 Vite。当前设备为 O1；页面通过设备报告的型号、功能位、均衡频段数与处理上限显示功能。后续型号可以沿用控制协议，不需要复制一套页面。设备数据不发送到云端。

## 启动

需要 Node.js 22.12 或更新版本：

```powershell
Set-Location Web
npm install
npm run dev
```

在支持 WebUSB 的 Chrome / Edge 中打开 http://127.0.0.1:5173/，点击“连接设备”并在浏览器弹窗选择设备。控制台需要 localhost 或 HTTPS，不能直接双击 HTML 使用。

```powershell
npm run build
npm run preview
```

`dist/` 可部署为 HTTPS 静态站点，不需要本机转发程序、账户或远端服务。

## 连接与页面

日常仅连接 XMOS 音频板 USB，控制板由底板供电。控制台认领现有 WinUSB 控制接口，Windows 音频接口继续用于播放；数字滤波、音量、静音及供电状态由 XMOS 与 STM32 的板间通信完成。不要把整个音频设备改成 WinUSB。STM32 USB 日志接口为可选诊断功能，网页不依赖它。

- **概览**：播放格式、接口位深、音量、累计时间、当前输出设置和纵向左右声道电平。
- **声音设置**：DAC 音量、静音、数字滤波、左右平衡、极性、开机音量、音量上限、淡入淡出、自动静音、音效预设和交叉馈送。滤波与输出设置选中后应用并自动保存，音效预设保留应用确认。
- **均衡器**：自由添加、删除和拖动频段，编辑类型、频率、增益、Q 与前级，导入外部参数 EQ 或导出 JSON。
- **设备设置**：型号、处理上限、播放计时清零、USB 模式和可展开的诊断信息。

系统状态保留一个指示：正常时显示“正常”，多个异常每 2 秒轮换。连接与应用成功不弹出例行通知，只显示必要的错误与保存状态。

默认深色，使用 Element Plus 官方深色主题。右上角太阳/月亮按钮切换浅色、深色，并在当前浏览器保存选择；未保存选择时始终默认深色。

侧栏顶部使用 AntDec 文本标识。用户静音在设备回读成功后自动保存在当前浏览器，再次连接并等控制板就绪后恢复。旧控制板沿用浏览器最近音量；支持输出设置的控制板使用设备的开机音量，网页连接时保留设备当前音量，避免旧浏览器记忆覆盖开机设置。主题、EQ 草稿和“实时应用”偏好也会自动保留。

数字滤波由设备保存，网页不会用浏览器中的旧滤波值覆盖设备。新版 XMOS 统一管理输出配置主副本、重连恢复和自动保存，STM32 保存本地备份并执行设置；板上按键修改也会同步。设备冷启动先在 DAC 静音初始化阶段恢复控制板备份，再按版本协调 XMOS 主副本，不需要网页连接。旧版组合仍使用控制板本地保存；缺少掉电记忆能力时显示更新提示。

本地设置按控制协议和型号区分；设备未提供唯一序列号，因此同一浏览器、同一站点下的同型号设备共用设置。更换浏览器、域名或清除站点数据后，本地记忆不会保留。已写入设备的滤波、EQ 与音效不受影响。

标准 UAC2 为默认档位。山灵与飞傲标识是实验配置，厂商驱动绑定和 ASIO 尚未验证。切换 USB 模式需要弹窗确认，会中断播放并重新枚举。

音量滑杆从 -100 dB 到设备设置的最大音量，使用听音曲线映射；默认上限 0 dB 时中点约 -25 dB，上段提供更细的调节。旁边的数字输入可以精确设置 0.5 dB 步进；显示及回读为主音量的实际分贝值。当前浏览器授权仍有效且仅有一台 AntDec 时，再次连接可复用授权，多个设备仍由浏览器选择。设备不再提供写死的 USB 序列号，重新插拔或重启浏览器后可能需要重新选择设备。

## 输出设置

需要控制板和 XMOS 都支持输出设置协议。网页同时检查音频板功能位、控制板能力与参数版本；缺少支持时显示对应更新提示并禁用控件。参数写入后核对带编号的执行确认和参数回读。新固件由 XMOS 管理版本、主副本和自动保存，控制板保留输出配置备份；同步期间禁用输出控件并显示同步状态，失败后由设备自动重试。主配置的保存状态由 XMOS 回报，旧固件组合继续显示控制板本地保存状态。网页关闭后设备仍自行工作。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| 左右平衡 | 向左或向右最多 12 dB，0.5 dB 步进 | 居中 |
| 左右极性反转 | 两声道分别选择 | 均不反转 |
| 开机音量 | -100 dB 到最大音量，0.5 dB 步进 | -20 dB |
| 最大音量 | -100～0 dB，0.5 dB 步进 | 0 dB |
| 淡入速度 | 慢 / 标准 / 快 | 标准 |
| 淡出速度 | 慢 / 标准 / 快 | 标准 |
| 自动静音 | 开启 / 关闭 | 开启 |
| 静音门限 | 低 / 标准 / 高 | 标准 |
| 静音延时 | 短 / 标准 / 长 | 标准 |

左右平衡通过衰减另一声道实现。最大音量由控制板统一限制，网页、板上按键和诊断命令均受约束；降低上限时立即降低超限的当前音量，同时调整超限的开机音量。开机音量只用于控制板冷启动，采样率切换或 DAC 重新初始化保留当前主音量。

极性反转时先快速静音，再修改极性并恢复原静音状态。正常淡入淡出使用所选速度；采样率切换和供电故障保护使用固定快速静音，异常时钟保护保持芯片快速设置。

自动静音门限使用芯片的低、默认、高三个档位，退出门限自动高于进入门限，减少反复切换。门限作用于 PCM 的微弱数字信号；DSD 仍按芯片的静音码和直流条件判断。延时随采样率变化，在 48 kHz 下短、标准、长约为 99、364、1092 ms；网页在 PCM 时显示按当前采样率估算的时长，DSD 不显示毫秒估计。关闭普通自动静音仍保留供电与异常时钟保护。

## 实时 EQ 与保存

O1 最多支持十个频段，频率和类型可以自由选择，支持峰值、低架、高架、低通、高通；频率 20～40000 Hz，增益 ±18 dB，Q 0.10～16。Q 小于 0.15 时按 0.15 计算；达到当前采样率 47% 的频段不参与处理。响应预览使用与设备相同的滤波公式，图上横轴按对数覆盖 20 Hz～40 kHz，响应曲线止于当前采样率的一半以下。

点击“添加频段”或双击图中空白处添加控制点；拖动控制点调整频率和增益，Q 和类型在表格中修改，低通、高通控制点只调频率。点击表格或控制点会选中对应频段。控制点支持键盘方向键调整，Delete / Backspace 删除，Shift 配合左右键细调频率、配合上下键以 1 dB 调整。删除频段释放设备槽位，清空会删除全部频段并恢复自动余量。读取旧固件默认的十个零增益频段时，页面将其整理为空白布局，首次编辑时再写回，不在读取时修改设备。后续型号按设备报告的容量限制频段数。

“实时应用”默认开启，编辑过程约每 160 ms 合并下发变化的频段，自动选择自定义 EQ，无需停止播放。关闭实时应用后可以编辑草稿，再点击“应用 EQ”。草稿每次编辑都会自动保留，重连时恢复；实时应用关闭时恢复草稿不会下发设备。“读取”使用设备参数覆盖本地草稿。

EQ 和交叉馈送仅处理最高 192 kHz PCM；高于该速率、原生 DSD 和 DoP 自动直通。可以预先设置这些格式下的 EQ 参数，回到受支持的 PCM 时才生效。前级 0 表示自动余量，按最大正增益衰减；手动前级范围 −36～−0.01 dB，多个频段叠加仍需要足够余量。

应用后立即记住最后成功下发的 XMOS 音效、十段参数、前级及交叉馈送。新版 XMOS 在停止调整约 2 秒、音频接口关闭且连续空闲至少 500 ms 后，自行写入完整配置，关闭网页也会继续保存；播放期间的新设置保留在设备运行内存，浏览器另存待落盘恢复副本。暂停若仍保持音频接口打开，保存继续等待。连续修改合并，保存失败由 XMOS 依次等待 5、10、20、30 秒重试，之后保持 30 秒。页面读取设备结果，确认成功才显示“已自动保存”，不再自行安排保存计时或发起重试。

未提供后台管理能力的旧 XMOS 固件继续由网页在停止调整和音频空闲后请求保存，并按相同间隔重试；这种组合关闭网页后无法保证继续写入。设备在普通控制请求中仍检查至少 500 ms 空闲。界面没有手动保存或重试按钮。

关闭网页或断电前若设备尚未完成写入，当前浏览器会保留待保存参数；下一次连接相同型号时恢复并继续自动保存。已经完成设备保存的音效以设备当前参数为准。未应用的 EQ 草稿独立保留，不会因保存此前已应用的音效而被当作已写入设备。

## EQ 文件

点击“导入”选择本地文件，预览中显示格式、频段、启用状态、前级和必要的精度调整。确认后替换整套自定义 EQ，未使用的设备槽位关闭，避免旧频段叠加；实时应用关闭时仅替换并保留草稿，点击“应用 EQ”后参与设备自动保存。实时应用开启时导入后自动应用并安排保存。文件在浏览器本地解析。

| 格式 | 支持内容 |
| --- | --- |
| Equalizer APO / AutoEQ 参数文本 `.txt`、`.peq` | `Preamp`，`Filter ...: ON/OFF`，PK/PEQ、LS/LSC/LSQ、HS/HSC/HSQ、LP/LPQ、HP/HPQ |
| REW 参数文本 `.txt` | 通用参数滤波器导出，包含 Fc、Gain、Q；忽略普通备注和导出时间 |
| JSON `.json` | AntDec 配置，或具有 `preamp` 与 `filters` 数组的参数配置；频段字段支持 `frequency` / `fc` |

参数文本示例：

```text
Preamp: -5.5 dB
Filter 1: ON LSC Fc 105 Hz Gain 5.5 dB Q 0.71
Filter 2: ON PK Fc 2500 Hz Gain -3.0 dB Q 1.40
Filter 3: OFF HSC Fc 10000 Hz Gain 1.0 dB Q 0.71
```

文本文件支持 UTF-8，以及带字节顺序标记的 UTF-16。频率按 1 Hz 取整，增益、Q 和前级按设备的 0.01 精度保存。没有手动前级或前级为 0 时使用自动余量；因为当前固件用 0 作为自动余量标记，无法表示手动固定 0 dB。

超过设备容量、频率/增益/Q 超范围、不支持的滤波类型、独立声道、其他处理指令都会提示错误。不会截断频段、自动改变滤波类型或执行 `Include`。GraphicEQ 是离散频响曲线，不能直接映射到有限数量的参数滤波器；当前明确提示改用 AutoEQ 等软件的 ParametricEQ 导出。卷积文件、插件和带指定阶数/斜率的滤波器也不支持。

“导出”保存当前草稿为 `AntDec-EQ.json`，包含前级、自动余量和每个频段的启用状态，可以重新导入。格式示例：

```json
{
  "format": "antdec-eq",
  "version": 1,
  "automatic": false,
  "preamp": -5.5,
  "bands": [
    { "type": 1, "frequency": 1000, "gain": -2.0, "q": 1.4, "enabled": true }
  ]
}
```

JSON 类型可以使用 1～5，对应峰值、低架、高架、低通、高通，也可以使用 `PEAKING`、`LOW_SHELF`、`HIGH_SHELF`、`LOW_PASS`、`HIGH_PASS`。`automatic: true` 时按自动余量应用，`preamp` 为手动值的留存。

## 电平与播放统计

电平是 EQ 后、DAC 音量前的 50 ms 窗口数字峰值，以 `20 × log10(峰值 / 满幅)` 换算为分贝，再按分贝等距绘制，纵向刻度 0～−90 dBFS，遥测分辨率 1 dB。幅度减半约下降 6 dB，降至十分之一约下降 20 dB。网页与屏幕采用相同的测量位置，小音量和本地 DAC 静音时仍可观察源信号动态；它不是实际模拟输出电平。

电平表直接响应上升，下降按约 24 dB/秒平滑回落；独立峰值标记保持 1 秒后，以约 12 dB/秒回落。−9 dB 以上为黄色、−3 dB 以上为红色，数值读数保持实际数字峰值。测量无效、停止音频流或断开时清除显示。它不代表耳机功率或实际声压。当前仅最高 192 kHz PCM 提供测量，DSD 与更高采样率显示不可用。

累计播放时间由设备统计并保存在 STM32，网页关闭后仍继续工作。音频接口打开时计时，包括静音数据；它不是曲目进度。每累计 120 秒保存一次，停止播放时补存，断电最多丢失最近约两分钟。设置清零通过确认弹窗操作，立即持久化；屏幕设置也可清零。记录在两页 Flash 内循环追加，一页写满才擦除下一页，并保留上一页的有效记录。

## 系列设备协议

USB 请求均为 AntDec 自有协议。0xAD 返回 32 字节设备信息：`ADC1`、协议版本、型号编号、功能位、PCM 上限、EQ 上限、频段数与型号名称。功能位依次为 DAC 控制、EQ、电平、累计时间、USB 模式、交叉馈送、输出设置、XMOS 后台管理。新版 O1 正常报告型号 1、功能位 0xFF；后台维护定时器不可用时不置管理位。共享协议定义在 `src/transports.ts`，能力映射在 `src/devices.ts`。

0xAB 返回 24 字节 STM32 状态及管理同步状态，0xAC 写入板间命令。新版 0xAE 为 18 字节，包含输出设置、管理状态及配置版本；网页仅在管理功能位存在时读取 18 字节，其余组合读取原有 16 字节。0xA0 的保存状态覆盖完整主配置，并提供后台管理异常标志；0xA4/0xA5 读写 EQ，0xA7 为保存请求，0xAA 读取电平。完整字段见 [XMOS 文档](../XMOS/README.md)。控制台不发送固件下载或擦除请求。STM32 仍用 J-Link 下载，XMOS 支持独立的 USB 升级工具。
