# AntDec-O1

基于 STM32F105RCT6、XMOS XU316 与 ES9039Q2M 的 USB 解码耳放。

## 工程与能力范围

| 项目 | 当前实现与适用范围 |
| --- | --- |
| XMOS 管理 | 音效与输出配置主副本、配置版本协调、重连恢复、后台自动保存和失败重试 |
| STM32 控制 | 分级上电、PG 状态监测、DAC 静音初始化与寄存器执行回读、最大音量保护、屏幕与按键、本地配置备份与累计时间 |
| PCM | 双声道 32-bit / 768 kHz；Windows 标准驱动已确认独占格式支持，44.1 / 48 / 768 kHz 静音数据流可启动 |
| DSD | 原生 DSD64～DSD512、DoP64～DoP256 数据路径；需确认主机驱动与实际输出时钟 |
| 音效 | 双声道 10 段均衡与低通交叉馈送；PCM 不高于 192 kHz 时启用。更高采样率及 DSD 自动直通 |
| MQA | 尚未集成经过验证的解码器。MQA 文件按普通 PCM 处理，固件不报告认证或展开率 |
| USB 模式 | 标准 UAC2、全速 UAC1，以及山灵/飞傲设备标识实验档位。后两者未验证厂商协议、驱动绑定或原生 ASIO |
| 验证范围 | 两端可编译、烧录；标准 USB 枚举与单根 USB 控制已实机确认。模拟输出质量、原生 DSD 和第三方 ASIO 仍需单独验证 |

设备标识变化不能证明第三方 ASIO 驱动兼容。最高采样率的描述符配置、存储空间和线程分配，也不能替代实时性能及音频输出测量。

当前配置管理代码需要 XMOS、STM32 配套更新。新职责分工和网页均已编译，尚未烧录验证；历史 USB 控制验证不涵盖此次新增的恢复、同步和 Flash 轮换逻辑。

## 文件目录

- `STM32/AntDec-O1/`：控制板 Cube 工程；底层外设由 Cube 生成，业务位于独立源文件与用户代码区域。
- `XMOS/app_antdec_o1/`：音频板应用；`dependencies.json` 固定依赖版本，`patches/` 保留本项目的库修正。
- `Web/`：网页控制台源码、依赖清单及锁定文件。
- `Mechanical/SolidWorks/` 与 `Mechanical/Print/`：外壳原生工程与 STL。
- `docs/enclosure.md`：外壳尺寸、打印及安装说明。
- `PCB/` 与 `references/Player/`：本机电路板工程与芯片资料，不纳入 Git。

参见 [STM32 固件说明](STM32/README.md) 与 [XMOS 固件说明](XMOS/README.md)。

## 真实硬件连接

| 信号 | 控制器连接 | 用途 |
| --- | --- | --- |
| LM27762 PGOOD | STM32 PC15 | 低电平表示正负电源正常 |
| ES9312 PG1 / PG2 | STM32 PA0 / PA1 | 多级故障状态脚，通过 ADC 读取状态脚电压 |
| DAC_AVDD_EN / VCCA_EN / AVCC_EN | STM32 PC1 / PC2 / PC3 | 依次开启 DAC 各路供电 |
| DAC_CHIP_EN | STM32 PC0 | 释放 DAC 复位 |
| AMP_ENABLE_REQUEST | STM32 PC4，经 R69 | 控制 OPA1622 使能 |
| DAC_I2C_SCL / SDA | STM32 PB6 / PB7 | DAC 配置与状态读取 |
| STM_XU_MUTE_STATUS | XMOS X0D37 → STM32 PC6 | 32 位脉宽遥测 |
| STM_XU_DSD_ON_STATUS | STM32 PC7 → XMOS X0D38 | 24 位脉宽控制 |
| XU_MCLK_RAW | XMOS X0D00 / X1D11 | 两个核组共用的音频主时钟 |
| BCLK / LRCLK / DATA | XMOS X1D22 / X1D34 / X1D13 | I2S；DSD 下复用为时钟、左声道、右声道 |
| CLK_SEL | XMOS X1D09 | 选择 49.152 MHz 或 45.1584 MHz 晶振 |

底板网表中的 `AUDIO_PATH_ENABLE`、`MCU_RUN_OK`、`MCU_NRST_SENSE`、`XU_POWER_PRESENT_N` 只接到控制排针，没有接入底板执行或检测电路。PB0 的软件输出不会切断实际音频通路；实际输出保护依赖 PC4 控制的 OPA1622 使能。当前三份网表没有 ISO7760，数字音频经串联电阻接入 DAC。

## XMOS 供电连接

音频板 USB 连接器 J202 的 5 V 未接入供电网络，只连接 USB 数据与地。上板使用时必须接通底板 JP1，使 SYS_3V3_DIG 通过 J6.17 → J203.18 到达 XU_3V3。JP1 未连接时，单独插入音频 USB 线不能启动 XMOS；USB 不枚举、没有遥测以及 DAC 无主时钟可同时出现。

## 电源流程与监测含义

上电保持耳放关闭、DAC 复位及各供电关闭。LM27762 PGOOD 连续正常 20 ms 后开启 AVDD，5 ms 后开启 VCCA，再过 5 ms 开启 ES9312。PG1/PG2 达到正常范围后释放 CHIP_EN，等待 10 ms，识别 DAC 的 0x63 芯片编号，静音写入配置并回读关键寄存器。再等待 20 ms，开启耳放，5 ms 后尝试解除静音；失败则关闭输出。

ES9039Q2M 手册建议 AVDD 先于 VCCA 约 200 us，随后开启 AVCC，最后释放芯片；本实现为 AVDD、VCCA 各保留 5 ms 等待，AVCC 开启至少 5 ms 且 PG1/PG2 同时正常连续 5 ms 后，才释放 DAC 芯片。这里的 5 ms 是固件选取的稳定余量，不是手册规定的固定时长。关闭时先切断耳放，再依次复位 DAC、关闭 AVCC、VCCA、AVDD。

PG1/PG2 是状态电压，不能用于测量实际 AVCC。按底板 10 kΩ 上拉至 3.3 V，ES9312 正常时约 3.3 V、警告时约 1.65 V、错误时约 0.48 V；固件以 2.4 V 作为启动正常门限、2.0 V 作为运行异常门限。实际数值会随上拉供电与电阻误差变化。参考 [ES9312 手册第 11 页](https://www.esstech.com/wp-content/uploads/2024/03/ES9312_DataSheet_v0.2.1.pdf)。

电源保护在主循环及每段屏幕传输之间执行。DAC 通信轮询间隔为 150 ms；软件轮询无法保证掉电瞬间、采样率切换及所有故障下的无冲击输出，这些需要实际波形与耳放输出测量。


## 网页设置

[本地网页控制台](Web/README.md)只需连接 XMOS 音频板 USB，即可查看播放、供电与解码状态，控制音量、数字滤波、音效和十段 EQ。XMOS 经板间通信读取和设置 STM32，控制板 USB 不参与日常网页操作。STM32 固件使用 J-Link 下载；XMOS 支持 USB 升级。

控制台使用 Vue 3 与 Element Plus，按设备报告的能力支持后续 AntDec 系列型号。网页与屏幕显示纵向对数声道电平和累计播放时间。时间每 2 分钟循环追加保存到 STM32 的两页存储区，停止播放时补存，并可在设备设置或屏幕菜单清零。系统状态正常时只显示“正常”，多个异常每两秒轮换。

电平表显示 DAC 音量衰减前的数字信号，范围 −90～0 dBFS，采用快升慢落和保持 1 秒的峰值标记，小音量时仍能观察源信号动态。

网页提供频响预览、频段滑杆和实时 EQ。新版 XMOS 统一管理音效和输出设置的主副本，停止调整约两秒、音频接口关闭且连续空闲至少 500 ms 后后台写入最后两个 Flash 扇区，关闭网页仍可保存，失败自动重试。USB 档位切换先保存完整配置，再重启。STM32 保留供电保护、DAC 执行与回读、最大音量约束、屏幕按键，以及输出配置备份和累计播放时间；启动与重连按版本协调，配置恢复期间保持静音，不主动提高当前音量。

输出设置包括滤波、左右平衡、极性反转、开机音量、最大音量、淡入淡出和自动静音参数。网页按两端固件能力开放控件，显示同步与保存状态，连接时保留设备当前音量。EQ 草稿、主题和用户静音由浏览器自动记忆，尚未落盘的已应用音效留有浏览器恢复副本。网页电平和 EQ 适用于最高 192 kHz PCM，较高采样率与 DSD 保持直通。具体存储布局、协议及升级边界见 [XMOS 说明](XMOS/README.md)。

## 打印外壳

[SolidWorks 外壳与装配说明](docs/enclosure.md)包含尺寸、打印方向、五金与安装步骤。模型目录仅保留 5 个原生零件、2 个装配和 5 个 STL。外壳按当前 PCB 和屏幕尺寸图设计，尺寸约 98.9 × 110 × 40 mm；底面、前后接口面及两侧合为一个底壳，仅顶盖独立。底面完全封闭，顶盖由侧面两颗短螺丝固定，电路板通过壳内盲孔和公母铜柱从上方安装。插接高度仍需首次装机确认。
