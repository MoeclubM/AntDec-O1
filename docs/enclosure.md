# AntDec O1 打印外壳

SolidWorks 2026 原生零件与装配，按当前三块 PCB 和提供的 35 × 56 mm 屏幕尺寸图设计。底板、四周侧壁和前后接口面合为一个打印实体，仅顶盖独立。外壳主体共两件，底面是连续封闭平面，顶盖由侧面前后错开的两颗 M3 短螺丝固定；按钮、压板和垫片为内部小件。屏幕使用内部两颗短螺丝和两个定位柱。

## 文件

| 文件或目录 | 用途 |

| `Mechanical/SolidWorks/AntDec_O1_Assembly.SLDASM` | 正常装配，引用零件在同一目录 |
| `Mechanical/SolidWorks/AntDec_O1_Exploded.SLDASM` | 拆分展示，一体底壳保持原位，顶盖抬起 |
| `Mechanical/SolidWorks/AntDec_O1_*.SLDPRT` | 保留草图、拉伸、切除特征的五种打印零件 |
| `Mechanical/Print/*.stl` | 五个打印文件，单位 mm，已放在建议打印方向 |

打开装配时，保持零件与装配的相对位置。两个装配仅包含底壳、顶盖、按钮、压板和打印垫片，不包含电路板、屏幕、接口或铜柱占位模型。两个装配都使用固定位置零件；拆分装配用于查看安装关系，不是运动机构。

## 结构与尺寸

单位均为 mm。以底板左下角为 XY 原点，Z 从底座外底面向上。音频接口在 +X 面，电源及 XMOS USB 在 −X 面。

| 壳体外形 | 98.9 × 110 × 40，按键高出上盖 0.7 |
| 壁、底和上盖厚度 | 2.4 |
| 外壳固定 | 两颗 M3×10 从相对侧壁进入，X=7 / 84，Z=33.6 |
| 底面 | 厚 2.4 的连续平面，没有贯穿孔、螺丝孔或通风槽 |
| 底壳 | 底面、前后接口面及左右侧壁为一个实体 |
| 上盖定位 | 内侧两条定位边和两个横向螺母座 |
| 底板 | 91 × 91 × 1.6，底面 Z=7.4 |
| XMOS 板 | 68.5 × 30 × 1.6，底面 Z=20 |
| 控制板 | 60 × 52 × 1.6，底面 Z=20 |
| 底板顶面到子板底面 | 11，使用 10 高铜柱和 1 厚垫片 |

| 按键帽 / 导向孔 | Ø5.4 / Ø5.9 |
| 按钮到开关顶面空隙 | 0.15，名义总行程约 0.6 |

底板六孔中心：`(5,24.5)`、`(5,88)`、`(30,24.5)`、`(30,88)`、`(78,12)`、`(50,20)`。XMOS 板与前四孔配合，控制板与后两孔配合。这些安装孔和铜柱保留，以支撑电路板和接口插拔受力。

前侧音频孔中心 Y 为 `43.0009`、`53.5`、`67.1`，Z 为 `12.25`、`11.25`、`11.25`。屏幕定位柱在 `(38.5,6)`、`(89.5,36)`，两颗短螺丝在 `(38.5,36)`、`(89.5,6)`。屏幕四个支柱都接触 PCB 孔周围，玻璃不承受固定压力。

合壳螺丝沿 Y 方向进入：一颗从 Y=−9.5 的侧壁、X=7 进入，另一颗从 Y=100.5 的侧壁、X=84 进入，中心高度均为 Z=33.6。螺母从顶盖横向螺母座的内侧开口放入，合盖后只需这两颗 M3×10，底面和顶面不穿合壳螺丝。

底壳支柱盲孔范围为 Z=3.3～7.4，孔底到外底面仍有 3.3 厚材料。采用 M2.5 公母铜柱，六角本体长 10、外螺柱长 6；螺柱从 Z=10 穿过 1 厚垫片和 1.6 厚底板，旋入打印支柱约 3.4，末端位于 Z=4，离盲孔底约 0.7。不要使用更长外螺柱。铜柱安装前可用 M2.5 丝锥从上方预攻盲孔；使用限深，保持底面封闭。

几何尺寸依据当前三块电路板外框、安装孔与接口坐标，屏幕由 J_TFT 位置和随附尺寸图定位；图中标识 ST7735，本目录只使用其机械尺寸。

**模型尚未实物试装。** 板厚、插接高度和接口中心高度来自标称尺寸与封装资料，装配未覆盖全部元件、焊锡和飞线，也没有进行热验证。首次装机需确认底板顶面到子板底面约 11、控制板顶面到屏幕 PCB 底面约 11.5；高度不同时应修改上盖支柱和按钮，不能用螺丝强拉到位。

音频插座前端距壳体前外侧约 4。4.4 插头根部宜小于 Ø10，3.5 插头根部宜小于 Ø8.8；粗外壳或短插头需按实物扩大开口。打印后先空壳试放电路板并确认常用插头的插入深度。

按当前封装外形，耳机座离前内壁约 1.6，XMOS USB 金属座离后内壁约 0.4；电路板和这些接口的名义外形都在内腔范围，可沿 Z 方向从上方放入。实物若有突出外形、焊锡或飞线，须先核对余量，不要强压电路板。

## 打印

建议 PETG，0.4 喷嘴、0.2 层高、4 圈外墙、5 层顶底、20%～30% 填充。导入 `Print` 文件时选择 mm、保持 100% 比例。

| 零件 | 文件名后缀 | 数量 | 打印姿态 |
| --- | --- | --- | --- |
| 一体底壳 | `Base` | 1 | 外底面贴平台，开口朝上 |
| 上盖 | `Lid` | 1 | 外表面贴平台，支柱、定位柱和螺母座向上 |
| 按钮 | `Button` | 3 | 细杆底端贴平台，可加小裙边 |
| 按键压板 | `Button_Retainer` | 1 | 平放 |
| 1 厚垫片 | `1mm_Shim` | 6 | 平放 |

一体底壳竖直打印，封闭外底面贴平台；前后接口孔和两处侧面合壳孔随侧壁一起成型。后侧 USB、电源开口上沿存在约 19、14 的桥接跨度；使用合适的桥接设置，必要时只在接口开口添加易拆的局部支撑，避免填满整个内腔。上盖螺母槽约 6 的跨度通常可直接桥接。打印后清除接口、定位柱和按钮孔毛刺，确认壳内没有残留支撑。按钮导向孔不涂胶。

## 五金

| 五金 | 数量 | 用途 |
| --- | --- | --- |
| M3×10 盘头或圆柱头螺丝 | 2 | 从侧面固定上盖 |
| M3 普通六角螺母 | 2 | 上盖内侧螺母座 |
| M2.5 公母六角铜柱，10+6 | 6 | 外螺柱固定底板到壳内盲孔，六角本体支撑子板 |
| M2.5×5 螺丝 | 6 | 子板固定到铜柱 |
| M2.5×5 螺丝 | 2 | 按键压板 |
| M1.6×4 螺丝 | 2 | 屏幕内部固定，无螺母 |
| 粘贴脚垫（可选） | 4 | 底面防滑 |

M3 螺母槽为对边 5.75、厚 2.6，适配常见对边 5.5、厚约 2.4 的普通螺母，不需要热熔嵌件。屏幕盲孔 Ø1.3，按键压板导孔 Ø2.2，轻拧短螺丝即可；反复拆装可分别预攻 M1.6、M2.5 螺纹。屏幕螺丝不能换成 M2.5/M3 或较长螺丝。

## 装配

1. 清理一体底壳接口孔和内部毛刺，空壳试放底板，确认接口没有顶住内壁。
2. 底板从上方垂直放在六个支柱上。每个底板孔上方放一片 1 厚垫片；将 10+6 公母铜柱的外螺柱从上方穿过垫片、底板，旋入打印支柱的盲孔。先全部轻拧，再逐一固定；不需要从底壳外侧穿螺丝。
3. 对准连接器，将 XMOS 板和控制板从上方垂直插好，用六颗 M2.5×5 固定到铜柱。连接器自然插合后应与铜柱同时接触。前后接口面已是一体底壳的一部分，无需额外安装面板。
4. 上盖翻面，将两颗 M3 螺母从内侧开口放入螺母座。放入三个按钮，凸缘留在盖内，装上压板，用两颗 M2.5×5 轻拧固定，确认按钮能够回弹。
5. 屏幕玻璃朝窗口，把对应两个 Ø2 孔放在定位柱上，使 PCB 贴住四个支柱。从 PCB 背面使用两颗 M1.6×4 拧入另外两个支柱的盲孔。
6. 对准屏幕排针，垂直合盖。上盖定位边落在侧壁内侧，两个横向螺母座靠近相对侧壁的合壳孔。
7. 检查屏幕无挤压、按钮没有常按，从两侧拧入两颗 M3×10 固定上盖。不要用螺丝强行拉齐未对准的上盖。
8. 按需在平整底面粘贴脚垫；通风槽仅保留在顶盖。

拆盖只需卸下侧面两颗 M3×10，垂直抬盖退出屏幕排针。底壳前后接口面固定不拆，电路板仍按相反顺序从上方取出。控制板 USB 在内部，日常通过 XMOS USB 操作；控制板下载口拆盖后可接近。

## 修改与检查

原生零件保留独立特征，可直接在 SolidWorks 中修改。模型目录只保留 SolidWorks 原生工程和 STL；修改零件后重建两个装配，并从最新零件重新导出对应 STL。打印文件继续使用 mm 单位，并按上述打印姿态放置。

一体底壳为单个实体，五种打印零件均为封闭网格。按钮斜面在 Z=35.8 处半径约 3.2，压板上面 Z=35.6、孔半径 3.6，名义下压距离约 0.6。实际配合仍取决于打印收缩、开关公差和插接高度。
